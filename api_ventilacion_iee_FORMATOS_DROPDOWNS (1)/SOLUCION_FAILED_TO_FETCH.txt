ERROR: Failed to fetch

Significa que Google Sites no puede abrir conexión con Render. No es error de fórmula.

Comprobaciones:
1) En el HTML, sustituye https://TU-SERVICIO-RENDER.onrender.com por la URL real de Render.
2) La URL debe empezar por https://, no http://.
3) Abre en navegador: https://TU-SERVICIO-RENDER.onrender.com/api/health
   Debe devolver: {"ok":true}
4) En Render, el servicio debe estar en estado Live.
5) En Render, Start Command debe ser: npm start
6) Si has cambiado GitHub, espera a que Render termine el redeploy.
7) Si usas el plan gratuito, la primera petición puede tardar porque el servicio está dormido.
